# Mechanical CAD

Code-CAD in Python with build123d: the sources here describe this module's cut-outs, front label, light pipes and the fit check of its boards in the housing. The housing models themselves come from `lib/mech/`.

- Keep the Python venv outside the repo.
- Outputs: STEP (for the mould maker or CM), DXF (board outlines for KiCad), PDF drawings, PNG views for review.
