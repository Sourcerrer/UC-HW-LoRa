# Production guidelines

To be written once the boards are laid out. Planned sections:

1. Fab notes: stackup, copper weights, finish, IPC class 2, panelisation.
2. Assembly: SMT and through-hole process, torque for standoffs and terminals, build variants.
3. Programming over USB-C (MCUboot, signed image), identity and key provisioning, serial number, debug lock.
4. Test procedure on the common test jig (USB-C + 4-pin bus).
5. Safety tests where relevant (for example hipot between relay contacts and SELV).
6. Visual / AOI checks, labelling and packaging.
